Before you run this

MongoDB connection string

Kept in the server's memory for this session only and passed to the MongoDB scripts as MONGODB_URI. It's never written to a file. To skip this step, set MONGODB_URI before starting the server.

Reset the demo

Stops every running script, then runs clean_environment.py in both databases.
